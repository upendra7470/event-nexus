# Event Nexus

A modern platform for managing and organizing events. Event Nexus provides a seamless experience for creating, discovering, and attending events of all kinds.

## Features

- **Event Creation**: Easily create and customize events with detailed descriptions, dates, and locations.
- **Event Discovery**: Browse and search for events based on categories, dates, and locations.
- **User Management**: Manage user profiles, registrations, and attendance.
- **Responsive Design**: Fully responsive and accessible on all devices.

## Technologies Used

- **Frontend**: React, TypeScript, Vite
- **UI Components**: Radix UI, shadcn/ui
- **Styling**: Tailwind CSS
- **State Management**: React Query
- **Form Handling**: React Hook Form
- **Database**: Supabase
- **Testing**: Vitest, Playwright

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm or yarn
- Supabase account (for database setup)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/upendra7470/event-nexus.git
   ```

2. Navigate to the project directory:
   ```bash
   cd event-nexus
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Set up your Supabase project and update the environment variables in `.env` file.

5. Start the development server:
   ```bash
   npm run dev
   ```
